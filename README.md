# BLUWRN

BLUWRN is Bluw's portfolio, focused on graphic design: posters, event graphics, and print layouts. Programming is a secondary interest connected to computer science studies.

## Tech stack

- Next.js 16.4.3 and React 19.3.0
- CSS

## Features

- Six featured design projects and an archive of 27 artworks, with category filters and an image viewer.
- Light and dark themes, with the selection saved in the browser.
- About, toolkit, and contact sections.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

To create and run a production build:

```bash
npm run build
npm run start
```
